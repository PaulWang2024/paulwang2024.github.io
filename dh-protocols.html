On DH Protocols

Diffie–Hellman-based key exchange and the design and security analysis of authenticated key agreement protocols.

Research direction

Key exchange as a protocol problem

Diffie–Hellman key exchange is a fundamental mechanism in public-key cryptography. Its secure use in a real protocol requires careful treatment of peer authentication, ephemeral and long-term keys, session-key derivation, and the adversary's capabilities.

My interests include the design and analysis of authenticated key exchange protocols, with particular attention to rigorous security definitions and efficient constructions.

Areas of interest

  • Diffie–Hellman key agreement and authenticated key exchange (AKE)
  • Protocol authentication and session-key security
  • Provable security and protocol analysis
